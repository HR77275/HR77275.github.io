# Project media

Store images, GIFs, MP4/WebM videos, poster frames, and architecture diagrams here.
Reference them in data/projects.ts as /media/your-file.webp.
Use descriptive filenames and alt text. Do not publish confidential employer data.
Prefer WebP/AVIF images and compressed short videos with local poster frames.
Videos use preload="none", responsive sizing, playsInline, and controls. Autoplay is opt-in and muted.
Add .vtt captions for speech and descriptive captions for visual results.
